Teaching assistant for the core undergraduate course in control systems. Held office hours and graded homework and exams.

## Course Description

Analysis and design of feedback control systems using classical methods. Topics include proportional-integral-derivative (PID) control, root locus techniques, Bode plots, Nyquist stability criterion, gain and phase margins, and closed-loop performance specifications. Students implement and test controllers in laboratory experiments on physical dynamic systems.
