# yohanjohn307.github.io

Personal academic website of Yohan John, Ph.D. candidate in Mechanical Engineering at UC Santa Barbara. Live at [yohanjohn307.github.io](https://yohanjohn307.github.io).

Built with [Academic Pages](https://github.com/academicpages/academicpages.github.io), a Jekyll theme for GitHub Pages.

## Running locally

```bash
bundle install
bundle exec jekyll serve
```

Then open [http://localhost:4000](http://localhost:4000) in your browser.

## Structure

| Path | Content |
|------|---------|
| `_config.yml` | Site-wide settings (name, bio, social links) |
| `_pages/about.md` | Home page |
| `_pages/cv.md` | CV page |
| `_publications/` | Publication entries |
| `_teaching/` | Teaching entries |
| `images/` | Images |
